# 导演引导与专业 Agent 参与的基线

目标：先判断“未选择、未加载、未委派、运行失败、引导无效”分别发生在哪里，再决定路由架构如何改。

基线：V1.2；候选：V1.3 观测组件。注意本轮只改变观测，不改变调度策略，不应预期导演效果自动提升。

第一批用例建议覆盖新需求、体验调整、缺陷修复、纯文档维护与批准前变更。由独立评审预先标注导演/原生子 Agent 是否适用，使用相同模型、推理预算、权限与验收。后续路由改造另建 EXP，不混入这一基线实验。

记录 Trace、WorkRun、验收与人工操作时间，失败和返工全部入组；每条评估关联实际证据。用量不可得保留 null，来源边界未覆盖保持未知。

当前结果：NOT_RUN。没有真实 Codex/Claude 登录运行、基线样本、Token 增幅或提效结论。仓库测试中的 fixture 只验证采集/统计程序，不纳入本实验。

决策：待真实数据后评审。不会自动创建实验业务 Goal、批准记录或最终验收。
