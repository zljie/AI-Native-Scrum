# Codex 列表规范：浏览器适配示例

此目录是可独立运行的原生 HTML/JavaScript 示例，不是生产业务应用，不调用或模拟生产 API。页面使用明确标注的 12 条模拟记录。字段名仅属于本示例；接入真实项目时应映射实际数据契约，不得伪造创建人或时间。

## 批准规则

- 搜索区在表格上方。
- 分页区在表格下方。
- 表头末三列依次为 **创建人 → 最后更新时间 → 操作**。
- 窄屏保留该顺序，表格允许横向滚动。

## 运行

使用 Node 22 或 24：

```sh
cd examples/codex-list-contract
npm ci
npx playwright install --with-deps chromium
npm test
```

测试直接打开本地 HTML，不启动 Web 服务。已有合法可用 Chromium 时，可以设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指向其可执行文件；不能用它绕过环境安全限制。正常浏览页面也可以直接打开 `index.html`。

## 测试范围

`tests/list.spec.cjs` 包含 9 项测试：真实可见区域和尾列、搜索与分页行为、空结果、窄屏、四个刻意破坏的负例，以及找不到页面区域时失败。

四个负例分别将搜索下移、分页上移、审计列顺序交换、删除更新时间列。测试要求 DOM 检查器识别对应错误；没有识别时测试失败。正常页面存在错误同样会使测试失败。缺少浏览器或页面不能算通过，不设置跳过。

报告输出到 `test-results/results.json`，失败时保留截图和 trace。报告需要与实际代码及规范版本一起归档，不能复用过期报告。CI 运行此套测试只是示例验证，不能代替目标业务项目的路由登记、真实组件适配和业务验收。它没有验证真实服务端分页、网络失败恢复或 API 字段真实性。

## 目标项目适配

复用区域标识 `data-contract="search|table|pagination"`、可访问表头和测试检查思路；为真实页面替换 URL、数据准备及查询/分页断言。不要通过修改规范、删除测试、排除页面或伪造证据让验收通过。布局变化需有经批准的例外和对应测试。

仓库只有在启用相应 Required Check / 分支规则后才会阻止不合规合并。此示例不修改仓库权限，也不声称已开启分支保护。

机器可读摘要为 `test-results/contract-result.json`。只有全部浏览器测试实际执行通过且没有跳过时，摘要才记录四类成功检查；浏览器启动失败、测试缺失或失败都会输出失败状态。上层证据工具仍须绑定代码及规则版本，不能把摘要文件单独作为可信凭证。
