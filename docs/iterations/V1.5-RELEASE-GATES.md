## G03：原生父子 Agent 回执

在隔离测试范围获得以下原始宿主证据，验收人员在宿主中审阅。注意 Codex app-server Multi-Agent V2 的 `subAgentActivity` 子线程完成通知可能晚于父线程的 `turn/completed`，应在绑定同一父线程/turn 的前提下有界观察迟到事件，且缺失仍然 fail closed：
1. 父线程、父 turn 与委派任务同源；发生真实 `spawn_agent`。
2. 宿主返回不同于父线程的子线程；有可回溯的 child 事件。
3. 子 Agent 的完成状态可靠；工具本身 wait 返回不等于子 Agent 完成。
4. 子 Agent 的输出关联到实际受限任务、源码版本及交接；接收角色独立审查。
5. 无完整事件链时，控制器拒绝 native 回执；不得采用 fixture 替代。
